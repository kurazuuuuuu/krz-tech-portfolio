OpenBot Secretary

Privacy Policy / プライバシーポリシー — 2026-10-22

OpenBot Secretary は、くらず（Kurazu）が個人で運用する OpenBot 用の Google 連携です。運営者本人のアカウントだけで使うもので、ほかの人は利用できません。

扱うデータ

  • Gmail のメール（読み取りと下書きの作成）
  • Google カレンダーの予定（読み取りと、本人が確認したうえでの作成・変更）

使い道

本人の依頼に答えること、予定やメールを要約して本人に知らせることにだけ使います。

保存と共有

  • データと認証情報は、運営者本人が管理するサーバーにだけ保存します。
  • 第三者に販売・共有しません。広告や AI モデルの学習には使いません。
  • Google API から受け取った情報の利用は、 Google API Services User Data Policy（Limited Use の要件を含む）に従います。

連携の解除

Google アカウントの「サードパーティ アクセス」 から、いつでもアクセス権を取り消せます。
